# Line 4, first mark

Goal (GOAL.md): turn raw Ethereum calldata into a readable, nested account of what a call will do, without the target contract's ABI.

The wall at `artifacts/line-4/wall.png` is a 1254 × 1254 pixel RGB PNG, the same size as the bare cave. The mark changes 53,470 pixels, all inside the bounding box `(307, 355)–(675, 656)`; every pixel outside the mark matches the supplied bare cave. It shows a filled Pepe in yellow ochre, wearing a red-ochre body. He has charcoal outlines, chalk eyes under heavy ochre lids and wide red lips. With an open hand he reaches toward three nested rings in red ochre and charcoal, standing for layers of calldata being opened. Each of his hands has four fingers and one thumb. The painting has no letters, numbers or frame. No visual requirement is known to be unmet; the figure is drawn more cleanly than a real cave painting would be.

The first tool is `tools/calldata_decoder/`. Its README has an offline command that decodes a real ZTO swap, plus live results.
